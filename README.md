# SleepTracker

Локальное веб-приложение для учёта времени отбоя и расчёта «штрафа» за опоздания ко сну.

**Текущая версия: 0.5.1** (схема `MAJ.MIN.PATCH`; синхронно с `VERSION` в `app.py`).

## Идея

Идеальное время отбоя — **23:00**.

- Отбой **позже 23:00** — штраф растёт на количество минут опоздания.
- Отбой **раньше 23:00** — штраф сгорает, но не более **120 минут** за один вечер (`MAX_BURN_PER_DAY`).
- **Ночные сдвиги**: отбой в интервале `00:00–11:59` считается продолжением **предыдущего вечера**.
- За один вечер допустимы **две записи**: вечерняя (`12:00–23:59`) и ночная (`00:00–11:59`).
  Они не перезаписывают друг друга, уникальный ключ записи — `(day, bedtime)`.

## Технологии

- Python 3.10+
- Flask 3.0+
- SQLite (файл `sleep.db` в каталоге приложения)
- matplotlib 3.7+ (график штрафа прямо на странице)

## Тесты

Регрессионная защита проекта — постоянный набор тестов в папке `tests/`:
`test_compute_state.py` (логика штрафа), `test_evening_anchor.py` (якоря,
ярусы, ключ вечера), `test_conflicts.py` (конфликты слотов и правки),
`test_import_csv.py` (импорт из CSV).

Запуск:

```bash
pip install pytest
python -m pytest tests/ -v
```

Правила: тесты версионируются вместе с кодом; перед каждым коммитом обязателен
прогон `pytest tests/ -v`; при добавлении фич количество тестов только растёт.

## Запуск

```bash
pip install -r requirements.txt
python app.py            # или launcher.py, или run.bat / run.sh
```

Откройте http://127.0.0.1:5000

Проверка работоспособности: `GET /healthz` → `ok`.

## Роуты

- `GET /` — главная страница: карточки статистики, график, форма, таблица истории
  (показываются последние 10 записей, кнопка «Показать еще» → `?show_all=1`)
- `POST /save` — сохранение/обновление записи (в т.ч. inline-правка времени в таблице)
- `POST /delete` — удаление записи (ночные удаления запоминаются в `deleted_nights`)
- `GET /healthz` — проверка работоспособности

## База данных

`sleep_entries`:
- `day TEXT NOT NULL` — дата в формате `YYYY-MM-DD`
- `bedtime TEXT NOT NULL` — время в формате `HH:MM`
- `UNIQUE(day, bedtime)`

`deleted_nights`:
- `evening_day TEXT PRIMARY KEY` — память об удалённых ночных записях; нужна,
  чтобы правка вида «15.10 23:40 → 15.10 01:19» не перезаписывала ночную запись
  соседнего вечера.

## Импорт истории из CSV

```bat
python import_history.py history.csv
sleeptracker.exe --import history.csv
```

Поддерживается формат Excel-экспорта с разделителем `;` (колонки: дата; отбой;
дельта; штраф; день недели; часы; комментарий) и простой формат `day,bedtime`.
Пустые строки-заготовки (будущие даты в Excel) и строки с `???` вместо времени
игнорируются; время вида `0:19` нормализуется в `00:19`. Флаг `--dry-run`
показывает, что будет импортировано, без записи в базу. Дубликаты пропускаются
(INSERT OR IGNORE).

## Сборка .exe

```bat
build_exe.bat
```

Результат — `dist\sleeptracker.exe`. Запуск без аргументов поднимает сервер и
самостоятельно открывает браузер по адресу http://127.0.0.1:<порт>/ (порт
подбирается автоматически, если 5000 занят). `sleeptracker.exe --import
history.csv` импортирует историю.

Файл базы данных `sleep.db` создаётся **рядом с .exe** (или рядом со скриптом
при запуске из исходников). Структура БД стабильна с версии 0.4.0 — файл базы
можно переносить между версиями программы. Переопределить расположение базы
можно переменной окружения `SLEEPTRACKER_DB`.

## Локальное развертывание из исходников (без сборки .exe)

1. Установите Python 3.10+ (при установке включите «Add Python to PATH»).
2. В папке с исходниками создайте виртуальное окружение и установите зависимости:
   ```bat
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Запустите приложение: `python app.py` (или `run.bat`) и откройте
   http://127.0.0.1:5000. База `sleep.db` лежит в этой же папке.

Обновление до новой версии: распакуйте новый архив в отдельную папку, выполните
шаги 2–3 и скопируйте `sleep.db` из старой папки в новую (структура БД не меняется).

## Версионирование

Схема `MAJ.MIN.PATCH`:
- **MIN** растёт при каждой новой успешной функции (PATCH сбрасывается в 0);
- **PATCH** растёт при исправлениях и доработках;
- **MAJ** растёт только при слиянии в `main` (релизы).

## Изменения версии 0.4.1

- История сортируется от последней даты к более ранним.
- Исправлена привязка ночных записей: отбой `22.10 00:19` относится к вечеру
  21.10 и отображается под этой датой с бейджем «ночь» (без дублирования
  времени текстом — только поле правки).
- При правке времени отбоя через историю штраф в карточках и на графике
  пересчитывается корректно.
- Одна дата — один вечерний отбой: повторная вечерняя запись того же дня
  заменяет предыдущую; ночная запись той же даты — отдельная сущность
  (продолжение предыдущего вечера), она не затирается.
- Импорт CSV: кириллица в выводе консоли Git Bash, автоопределение кодировки
  файла (UTF-8 / cp1251), игнорирование пустых строк-заготовок и `???`.
- Тёмная тема интерфейса; база `sleep.db` кладётся рядом с `.exe` (совместимость
  переноса между версиями сохранена, структура БД не менялась).

- Утверждена логика работы с записями после полуночи: внесение данных всегда

  22.02 и 00:33), а в истории/пересчёте сон относится к предыдущему вечеру
  (21.02). Правка «15.10 23:40 → 15.10 01:19» — обычная правка времени,
  перевалившего за полночь: существующая ночная запись того же вечера
  заменяется (UPDATE), соседние вечера не затрагиваются.
- Исправлен баг в `/save`: проверка «памяти об удалённых ночах» (`deleted_nights`)
  сравнивала строковый epoch-ключ с ISO-датой и никогда не срабатывала —
  корректно приведено к строке; блок «призрачных» ночей работает как задумано.
