# SleepTracker

Локальное веб-приложение для учёта времени отбоя и расчёта «штрафа» за опоздания ко сну.

## Идея

Идеальное время отбоя — **23:00**.

- Отбой **позже 23:00** — штраф растёт на количество минут опоздания.
- Отбой **раньше 23:00** — штраф сгорает, но не более **120 минут** за один вечер (`MAX_BURN_PER_DAY`).
- **Ночные сдвиги**: отбой в интервале `00:00–11:59` считается продолжением **предыдущего вечера**.
- За один вечер допустимы **две записи**: вечерняя (`12:00–23:59`) и ночная (`00:00–11:59`).
  Они не перезаписывают друг друга, уникальный ключ записи — `(day, bedtime)`.

## Технологии

- Python 3.10+
- Flask 3.0+
- SQLite (файл `sleep.db` в каталоге приложения)
- matplotlib 3.7+ (график штрафа прямо на странице)

## Структура проекта

| Файл | Назначение |
|---|---|
| `app.py` | Сервер Flask, логика штрафа (`compute_state`, `evening_anchor`, `night_key`), HTML-шаблон, роуты |
| `launcher.py` | Точка входа для PyInstaller: запуск сервера или импорт CSV (`--import`) |
| `import_history.py` | CLI-утилита импорта истории из CSV (`python import_history.py history.csv`) |
| `run.bat` / `run.sh` | Скрипты автозапуска (Windows / Linux-macOS) |
| `build_exe.bat` | Сборка `.exe` через PyInstaller |
| `requirements.txt` | Зависимости |

## Запуск

```bash
pip install -r requirements.txt
python app.py            # или launcher.py, или run.bat / run.sh
```

Откройте http://127.0.0.1:5000

Проверка работоспособности: `GET /healthz` → `ok`.

## Роуты

- `GET /` — главная страница: карточки статистики, график, форма, таблица истории
  (показываются последние 10 записей, кнопка «Показать еще» → `?show_all=1`)
- `POST /save` — сохранение/обновление записи (в т.ч. inline-правка времени в таблице)
- `POST /delete` — удаление записи (ночные удаления запоминаются в `deleted_nights`)
- `GET /healthz` — проверка работоспособности

## База данных

`sleep_entries`:
- `day TEXT NOT NULL` — дата в формате `YYYY-MM-DD`
- `bedtime TEXT NOT NULL` — время в формате `HH:MM`
- `UNIQUE(day, bedtime)`

`deleted_nights`:
- `evening_day TEXT PRIMARY KEY` — память об удалённых ночных записях; нужна,
  чтобы правка вида «15.10 23:40 → 15.10 01:19» не перезаписывала ночную запись
  соседнего вечера.

## Импорт истории из CSV

```bat
python import_history.py history.csv
sleeptracker.exe --import history.csv
```

Поддерживается формат Excel-экспорта с разделителем `;` (колонки: дата; отбой;
дельта; штраф; день недели; часы; комментарий) и простой формат `day,bedtime`.
Пустые строки-заготовки (будущие даты в Excel) и строки с `???` вместо времени
игнорируются; время вида `0:19` нормализуется в `00:19`. Флаг `--dry-run`
показывает, что будет импортировано, без записи в базу. Дубликаты пропускаются
(INSERT OR IGNORE).

## Сборка .exe

```bat
build_exe.bat
```

Результат — `dist\sleeptracker.exe`. Запуск без аргументов поднимает сервер и
самостоятельно открывает браузер по адресу http://127.0.0.1:<порт>/ (порт
подбирается автоматически, если 5000 занят). `sleeptracker.exe --import
history.csv` импортирует историю.
