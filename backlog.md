# BACKLOG: SleepTracker

Этот документ содержит план развития проекта SleepTracker. Он служит "единым источником истины" для разработчика и AI-агента (Qwen Coder).

Инструкция для AI-агента: Перед началом работы над новой задачей прочитай этот файл, чтобы понимать контекст, текущий этап и правила проекта. НЕ модифицируй этот файл автоматически — галочки ставит только владелец проекта после проверки качества.

---

## Правила разработки (Неизменно)
1. Ветвление: Вся разработка ведется в ветке qwen (или feature/название). Прямой push в main запрещен.
2. Тесты: Перед любым коммитом ОБЯЗАТЕЛЬНО запускай python -m pytest tests/ -q. Если тесты падают — чини код, а не тесты.
3. Ядро логики: Функции compute_state, evening_anchor, level_of, night_key, effective_evening в app.py считаются стабильными. Не меняй их логику без прямой команды.
4. Версионирование: MAJ.MIN.PATCH. MINOR растет при добавлении новых фич (например, 0.4 -> 0.5), PATCH — при багфиксах и доработке тестов.
