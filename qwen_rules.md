# Правила работы Qwen Coder с проектом SleepTracker

Этот файл содержит обязательные правила для AI-агента (Qwen Coder). Читай его перед каждым заданием.

## Неизменные правила

1. Ветвление Git
   - Вся разработка ведётся ТОЛЬКО в ветке qwen (или feature/название)
   - Прямой push в main ЗАПРЕЩЁН
   - Перед каждым коммитом: git pull origin main (чтобы избежать конфликтов)

2. Тестирование
   - Перед ЛЮБЫМ коммитом ОБЯЗАТЕЛЬНО запускай: python -m pytest tests/ -q
   - Если тесты падают — чини код, НЕ тесты
   - Никогда не удаляй и не изменяй существующие тесты без прямой команды

3. Защищённое ядро
   - Функции compute_state, evening_anchor, level_of, night_key, effective_evening в app.py — стабильны
   - НЕ меняй их логику без явного разрешения
   - НЕ оптимизируй их "для красоты"

4. Бизнес-логика (НИКОГДА не менять)
   - Идеальный отбой: 23:00 (IDEAL_MINUTES = 1380)
   - Штраф растёт при опоздании после 23:00
   - Штраф сгорает при раннем отбое, но максимум MAX_BURN_PER_DAY = 120 мин за вечер
   - Штраф НИКОГДА не уходит в минус (< 0)
   - Отбой 00:00-11:59 — продолжение ПРЕДЫДУЩЕГО вечера (night_key)
   - За вечер допустимы 2 записи: вечерняя (lvl 0) и ночная (lvl 1)

5. Стиль коммитов
   - Используй Conventional Commits: type: description
   - Примеры: 
     - feat: add Chart.js graph
     - fix: correct night anchor calculation
     - chore: update dependencies
     - test: add regression tests for compute_state

6. Работа с backlog.md
   - Читай файл для понимания контекста
   - НЕ модифицируй автоматически
   - Отмечай выполненное только по прямой команде

7. Окружение coder.qwen.ai
   - Перед запуском тестов: pip uninstall -y libtmux (конфликт с pytest 9.x)
   - Токен GitHub передаётся в чате — используй его для git операций
   - После каждого git push выполняй git pull (чтобы не терять доступ)

## Технические стандарты

- Python: 3.8.6+ (совместимость с Windows 7)
- Flask: версии из requirements.txt (зафиксированы)
- Тёмная тема интерфейса — НЕ менять цвета без команды
- Русские дни недели (Пн, Вт, Ср...) — НЕ менять на английские
