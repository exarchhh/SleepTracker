# Changelog

Все значимые изменения проекта SleepTracker.

## [0.7.3] - 2026-11-11

### Изменено
- `AGENTS.md`: добавлена обязательная секция «Начало сессии» — `export TZ=Europe/Moscow`, авторство коммитов «Z.ai Agent» с приватным noreply-адресом владельца (песочницы пересоздаются между сессиями, поэтому настройка живёт в контракте); убрано захардкоженное число тестов, правило жизненного цикла тестов переформулировано («при удалении фичи её тесты удаляются вместе с ней»); `DECISIONS.md` дополнен записями 10–11
- `launcher.py`: убран режим импорта CSV (`--import`) — остался только запуск сервера
- `README.md`, `BACKLOG.md`, `.gitignore`: зачистка живых упоминаний импорта истории (исторические записи CHANGELOG и выполненные этапы не тронуты)

### Удалено
- `import_history.py` — одноразовый мигратор Excel→SQLite своё отработал (октябрь 2026); восстановление возможно из git-истории
- `tests/test_import_csv.py` — тесты удалённой фичи удаляются вместе с ней
- Раздел README «Импорт истории из CSV» и упоминание `sleeptracker.exe --import history.csv` в «Сборке .exe»
- Пункт BACKLOG Этапа 3 «Импорт через UI» (запись 11 в `DECISIONS.md`)

## [0.7.2] - 2026-11-11

### Добавлено
- `AGENTS.md` — контракт для любого AI-агента-кодера, нейтральный к модели (замена `QWEN_RULES.md`): роль и процесс, замороженный стек, правила Git и версионирования, тесты, защищённое ядро `core.py`, работа с `BACKLOG.md`/`DECISIONS.md`, правила обращения с токеном GitHub, шаблон отчёта
- `DECISIONS.md` — append-only журнал принятых решений («почему так») с 9 стартовыми записями: формат работы (менеджер/кодер/владелец), точка истины по версии, замороженный стек и PYSEC-2026-2151, ветка `dev`, переименование правил, схема бэкапа, развилка Android-версии, доступ к репозиторию через PAT, понижение «ORDER BY в SQL» по результатам аудита

### Изменено
- Переработана документация: `README.md` и `BACKLOG.md` синхронизированы с новой структурой правил; упоминания Qwen заменены нейтральным «AI-агент»
- Разработка переведена на ветку `dev` (вместо ветки `qwen`); `QWEN_RULES.md` удалён — содержимое перенесено в `AGENTS.md`
- Уточнён порядок версионирования и релизов: MAJOR — только по прямому решению владельца; релизы оформляет владелец (проверка глазами → merge `dev` → `main` → тег `v<VERSION>`); первый тег — v0.8.0
- `README.md`: честная формулировка зависимостей — точно зафиксирован только Flask 3.0.3, фиксация транзитивных зависимостей через `constraints.txt` запланирована; описание `deleted_nights.evening_day` приведено в соответствие с кодом (хранится числовой ключ вечера из `night_key()`, в TEXT-колонке)
- `BACKLOG.md`: в Этап 1.5 добавлены задачи аудита (проверка Host/Origin + Sec-Fetch-Site на POST /save и /delete, `constraints.txt`, `{{ chart_data | tojson }}`); пункт про `build_exe.bat` дополнен (убрать matplotlib-флаги, добавить `--add-data "templates;templates"` и `--hidden-import core`); в Этапе 2 уточнён минимальный бэкап (схема — в `DECISIONS.md`) и добавлена настройка «Хранить Х копий»; GitHub Actions запланирован сразу после Этапа 1.5 (pytest + bandit + pip-audit); задача «ORDER BY в SQL» перенесена в «Техническое обслуживание» с понижением по результатам аудита

## [0.6.3] - 2026-10-29

### Исправлено
- Динамическое масштабирование оси Y графика: отступы (padding) теперь рассчитываются как 10% от диапазона данных за выбранный период, а не от абсолютных значений. Это предотвращает "сплющивание" графика при высоких значениях штрафа.

## [0.6.2] - 2026-10-28

### Добавлено
- Селектор периодов над графиком (Неделя, 2 недели, Месяц, 3 месяца, Полгода, Год, Календарный год).
- Динамические карточки статистики: "Текущий стрик" и "Среднее время отбоя" (пересчитываются при смене периода).
