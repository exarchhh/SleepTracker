# BACKLOG: SleepTracker

Этот документ содержит план развития проекта SleepTracker. Он служит "единым источником истины" для разработчика и AI-агента.

> Инструкция для AI-агента: Перед началом работы над новой задачей прочитай этот файл, чтобы понимать контекст, текущий этап и правила проекта. Обоснования принятых решений ("почему так") — в `DECISIONS.md`. НЕ модифицируй этот файл автоматически — галочки `[x]` ставит ТОЛЬКО владелец проекта после визуальной проверки качества. Подробная история изменений хранится в Git и CHANGELOG.md.

---

## Правила разработки (Неизменно)

1. **Ветвление:** Вся разработка ведется в ветке `dev`. Прямой push в `main` запрещен.
2. **Тесты:** Перед любым коммитом ОБЯЗАТЕЛЬНО запускай `python -m pytest tests/ -q`. Если тесты падают — чини код, а не тесты.
3. **Ядро логики:** Функции в `core.py` (`compute_state`, `evening_anchor`, `level_of`, `night_key`, `effective_evening`) считаются стабильными. Не меняй их логику без прямой команды.
4. **Версионирование:** MAJ.MIN.PATCH. MINOR растет при добавлении новых фич, PATCH — при багфиксах и рефакторинге. При каждом изменении VERSION ОБЯЗАТЕЛЬНО обнови `CHANGELOG.md` в том же коммите, указав все изменения с момента предыдущей версии.
